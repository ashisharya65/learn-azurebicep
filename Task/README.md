# Assignment: Deploy a Scalable Web Server Environment Using Azure Bicep 

## Objective 
You will use Azure Bicep to: 
 - Create a secure virtual network. 
 - Deploy a Linux VM with a custom NSG and managed identity. 
 - Attach a data disk. 
 - Configure a custom script extension to set up NGINX. 
 - Parameterize your Bicep template for reusability. 
 - Validate the deployment using the Azure CLI. 

## Deliverables 
 - Bicep file (main.bicep) with modular structure. 
 - Parameter file (main.parameters.json) for customization. 
 - Deployment validation screenshot from Azure CLI or Portal. 
 - Screenshot of NGINX landing page hosted on your VM.
